# 컴퓨터교육석사 논문검색

주제를 고르거나 검색하면 OpenAlex(무료 학술 데이터베이스)에서 논문을 찾아 무료 원문 링크와 출처를 보여주는 개인 페이지입니다.

- 주제 칩 수정: `app.js` 맨 위의 `CATEGORIES`를 고치세요.
- 저장한 논문, 읽음 상태, 메모는 사용 중인 브라우저에만 저장됩니다.
- 합법적으로 공개된 무료 원문만 연결됩니다. 유료 논문은 출처·DOI 페이지로 이동합니다.
- 한국 논문은 검색창 아래 DBpia·RISS 버튼을 쓰세요.
- 배포: Settings → Pages → Deploy from a branch → main → / (root)
